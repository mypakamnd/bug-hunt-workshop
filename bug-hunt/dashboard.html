ยังไม่ได้เชื่อมฐานข้อมูล

ตอนนี้หน้าเกมเก็บคำตอบไว้ในเครื่องผู้เล่นแต่ละคน dashboard จึงยังไม่มีข้อมูล เชื่อม Supabase ตามนี้:

  1. สร้างโปรเจกต์ฟรีที่ supabase.com
  2. เปิด SQL Editor แล้วรันไฟล์ supabase-setup.sql
  3. เปิด Project Settings → API คัดลอก Project URL และ anon / publishable key
  4. ใส่ทั้งสองค่าใน bug-hunt/config.js แล้ว deploy ใหม่
