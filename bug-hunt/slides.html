INTRO04 / MINDSET

Tester Mindset vs QA Mindset

TESTER
  • "ส่งงานมา เดี๋ยวเทสให้"
  • หาบั๊กให้เจอมากที่สุด
  • ทำตาม test case
  • เจอบั๊ก ส่งกลับให้ dev
  • วัดผลจากจำนวนบั๊ก
QA
  • "ขอเข้าไปคุยตั้งแต่ตอนออกแบบ"
  • ทำให้เกิดบั๊กน้อยที่สุด
  • ถามว่า test case ครอบคลุมพอหรือยัง
  • หาสาเหตุและป้องกันครั้งหน้า
  • วัดผลจากความมั่นใจตอน release

การเทสยังเป็นทักษะหลัก QA ไม่ได้เลิกเทส แต่ขยายบทบาท
