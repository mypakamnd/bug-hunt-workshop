THRIVE · LEVEL 1WHAT IS A TEST MATRIX?

Test Matrix คืออะไร?

ตารางที่เอา สิ่งที่ผู้ใช้เลือกหรือเปลี่ยนได้ มาไขว้กัน · ทุกช่อง = 1 test case
1หามิติสิ่งที่เปลี่ยนแล้วผลลัพธ์อาจต่าง เช่น ขนาด, แบบ
2แบ่งค่าแต่ละมิติเป็นกลุ่มขนาด: เล็ก / กลาง / ใหญ่ · แบบ: ร้อน / เย็น
3ไขว้กัน ทุกช่องคือ 1 caseจำนวน case = ค่ามิติแรก × ค่ามิติที่สอง
ตัวอย่าง: สั่งกาแฟ
ขนาด / แบบร้อนเย็น
เล็กcase 1case 2
กลางcase 3case 4
ใหญ่case 5case 6

3 × 2 = 6 case · ช่องที่ยังไม่มี case จะเห็นทันที

ชื่อเทคนิค: Combinatorial Testing · มิติเยอะเกินไปใช้ Pairwise

เทคนิคเบื้องหลังกฎ Black-box test design · ชื่อมาตรฐานตาม ISTQB

เทคนิคคืออะไรในงานของเรา (QuickShift)
Combinatorial Testing (Test Matrix)ไขว้ค่าของหลายมิติที่ผู้ใช้เลือกได้ ทุกการผสมคือ 1 caseคำค้น 4 × เรียงตาม 2 = 8 case

Boundary Value Analysisเทสค่าที่ขอบของเงื่อนไข เพราะบั๊กชอบซ่อนตรงขอบอายุ 17 / 18

State Transition Testingเทสทุกสถานะที่ข้อมูลอยู่ได้ และการเปลี่ยนสถานะที่ทำได้ / ทำไม่ได้งานเปิดรับสมัครได้ · ปิดรับสมัครไม่ได้
Checklist + Error Guessingไล่รายการความเสี่ยงจากประสบการณ์ เช่น ออกกลางทาง ระบบล่ม ไม่มีข้อมูลRecommend Cases 9 ข้อ
